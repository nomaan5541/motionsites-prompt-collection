## 1. Core Privacy Philosophy: Zero Data Collection

The **MotionSites Prompts Collection** repository and its accompanying client-side web application are engineered with a strict, absolute **privacy-by-design** architecture. 

- We do **not** collect, harvest, aggregate, process, store, sell, or rent any Personally Identifiable Information (PII).
- We do **not** require user accounts, email registrations, or authentication to browse the collection, search prompts, or copy code.
- We do **not** embed tracking pixels, user telemetry agents, fingerprinting scripts, or third-party marketing trackers in this web application.

## 2. Information Handled Locally on Your Device

### Browser Local Storage
The web application may utilize standard HTML5 `localStorage` on your local client device strictly for essential, non-tracking user interface state management, such as:
1. **User Theme Preference**: Storing your chosen UI appearance (Dark Mode or Light Mode).
2. **Search Preferences & Filters**: Temporarily caching recent search filters or category selections for interface performance.

This data is stored purely within your local browser sandbox and is never transmitted to any remote server or external database.
